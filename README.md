# 岁阅

用于梳理史书、小说中事件与人物关系的静态网页应用。

直接用浏览器打开 `index.html`。三维视图依赖在线加载的 Three.js；书籍内容会保存在浏览器本地，也可以通过右上角导出为两份 JSON 文本文件。载入时同时选择这两份文件即可。

## 书籍文件格式

书籍采用两份 UTF-8 JSON 文本：

- `人物关系.json` 包含 `people` 和 `relations`。人物的 `born`、`died` 接受任意精度的日期文本；有至少一名人物时必须且只能有一个 `main: true`。关系边以 `from`、`to` 引用人物 ID，`label` 表示关系，`note` 为备注。
- `事件记录.json` 包含 `events`。`title` 为空时表示无事件的位置记录；`year` 是三维排序所需的数值年份，`date` 保留原始时间文本。

应用内置一份“三国纪事”示例，可直接导出作为格式模板。
